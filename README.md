# Catálogo Interativo

Projeto da atividade de Construção de Interface com Frameworks, desenvolvido em React + Vite.

## Integrantes

Preencha com os nomes completos da equipe.

## O que foi feito

- Catálogo inicial com seis livros e status de disponibilidade.
- `SearchControls` captura o termo de busca; a lista é filtrada em tempo real com `useMemo`.
- `BookCard` é um componente independente que recebe cada livro via props.
- `AddBookForm` valida e inclui novos livros no estado do componente `App`, atualizando a tela imediatamente.

## Executar localmente

```bash
git clone <url-do-repositorio>
cd CONSTRU-O-DE-INTERFACE-COM-FRAMEWORKS
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no navegador.
